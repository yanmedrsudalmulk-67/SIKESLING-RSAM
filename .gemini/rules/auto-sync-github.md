# Rule: Auto-Commit & Auto-Push to GitHub

Setiap kali asisten Antigravity menyelesaikan modifikasi file, penambahan fitur, pembaruan data, atau perbaikan bug pada proyek SIKRESMI:
1. Jalankan `git add .` untuk menandai semua perubahan terkini.
2. Buat commit otomatis dengan pesan yang jelas (misal: `feat: ...`, `fix: ...`, atau `data: ...`).
3. Lakukan `git push origin main` secara langsung ke repository `https://github.com/yanmedrsudalmulk-67/SIKESLING-RSAM.git`.
4. Berikan konfirmasi status push pada akhir respon kepada pengguna tanpa perlu diminta.
